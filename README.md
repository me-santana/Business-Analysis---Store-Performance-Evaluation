# 🛍️ Business Analysis — Store Performance Evaluation

## 📝 Project Overview

This project presents a data-driven analysis of four **Alura Store** locations to support a strategic business decision. The main objective is to evaluate each store's performance and operational health using key performance indicators (KPIs) and identify which location should be considered for divestment.

The analysis focuses on financial performance, product categories, customer satisfaction, and logistics costs to provide an evidence-based recommendation.

## 🚀 Technologies & Tools

* **Python 3**
* **Pandas:** Data manipulation, cleaning, and analysis
* **Matplotlib:** Data visualization
* **Google Colab:** Cloud-based development environment

## 📂 Dataset

The analysis uses four CSV datasets, one for each store. The datasets contain information such as:

* `Product Name`
* `Product Category`
* `Unit Price`
* `Quantity Sold`
* `Purchase Rating` — customer satisfaction indicator
* `Shipping Cost`
* `Latitude` and `Longitude`

## 📊 Analysis Performed

The project evaluates the stores through five key analytical areas:

1. **Total Revenue** — comparison of overall sales performance
2. **Popular Product Categories** — identification of the most relevant categories
3. **Customer Satisfaction** — comparison of average purchase ratings
4. **Logistics Costs** — analysis of shipping expenses and operational efficiency
5. **Sales Highlights** — identification of products and sales patterns that stand out across stores

## 💡 Key Insights

* **Store 1:** Recorded the **lowest average customer rating** and the **highest shipping costs**, suggesting significant operational inefficiencies and potential customer experience issues.
* **Store 4:** Generated the **lowest overall revenue**, but demonstrated better logistics efficiency and strong customer satisfaction indicators.
* **Store 1** showed the most concerning combination of customer satisfaction and logistics performance.

## 🎯 Business Recommendation

Based on the analyzed KPIs, **Store 1 is recommended as the strongest candidate for divestment**.

Although revenue alone does not determine the decision, Store 1's combination of weaker customer satisfaction and higher logistics costs indicates greater operational challenges. Divesting this location could help reduce operational costs while protecting the overall customer experience and brand performance.

## 📌 Project Context

This project was originally developed as part of the **Alura Store Challenge**, applying Python and data analysis techniques to a business decision-making scenario.

The project demonstrates practical skills in **data cleaning, exploratory analysis, KPI evaluation, data visualization, and evidence-based business recommendations**.

# 🛍️ Projeto Alura Store: Análise de Desempenho para Tomada de Decisão

## 📝 Descrição do Projeto
Este projeto consiste em uma análise de dados detalhada de quatro unidades da empresa **Alura Store**. O objetivo principal é fornecer insumos técnicos para o Senhor João decidir qual das suas lojas deve ser vendida, baseando-se em indicadores de desempenho (KPIs) e saúde operacional.

## 🚀 Tecnologias Utilizadas
* **Python 3**
* **Pandas:** Manipulação e tratamento de dados.
* **Matplotlib:** Criação de visualizações gráficas.
* **Google Colab:** Ambiente de desenvolvimento em nuvem.

## 📂 Estrutura dos Dados
O projeto processa dados de quatro arquivos CSV (um para cada loja), contendo as seguintes colunas:
* `Nome do Produto`, `Categoria do Produto`
* `Preço Unitário`, `Quantidade Vendida`
* `Avaliação da compra` (Satisfação do cliente)
* `Valor do frete`
* `Latitude (lat)` e `Longitude (lon)`

## 📊 Análises Realizadas
O projeto foi estruturado para responder a perguntas estratégicas através de 5 visualizações principais:
1. **Faturamento Total**
2. **Categorias Populares**
3. **Satisfação**
4. **Custo Logístico (Frete)**
5. **Destaques de Venda**

## 💡 Principais Insights
* **Loja 1:** Apresentou a **menor média de avaliação** e o **frete mais caro**, indicando ineficiência operacional severa.
* **Loja 4:** Possui o menor faturamento, porém detém a melhor eficiência logística e ótimos índices de satisfação.
* **Recomendação Final:** A venda da **Loja 1** é sugerida para proteger a reputação da marca e reduzir custos logísticos.
